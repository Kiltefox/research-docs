任务概览
========

目标
----

模型输入为 ``tau`` 和 ``rewards``，输出 ``rho`` 的后验预测分布参数。
在 SUMO 环境中，``tau`` 不是时间序列，而是车辆-道路结构特征：
每辆车在出现时，对每条道路记录距离终点的距离和该道路的排队长度。

因此 ``rho`` 不应只被看作一个确定性回归标签，而应被看作条件分布
:math:`p(\rho \mid \tau, rewards)` 的统计量或后验预测结果。
模型默认输出均值 ``mu`` 与尺度 ``sigma``，必要时可扩展为混合分布参数。

输入
----

``tau``
   形状通常为 ``[N_vehicle, N_road, D_tau]``，例如 ``[1557, 114, 2]``。
   在 SUMO 场景中，``1557`` 表示车辆数，``114`` 表示道路数，
   ``2`` 个特征为距离终点的距离和该道路的排队长度。

``rewards``
   形状通常为 ``[N_vehicle, N_road]``，例如 ``[1557, 114]``，
   表示每辆车对每条道路各自的奖励。

``mask``
   形状通常为 ``[N_vehicle, N_road]``，用于标记有效车辆-道路位置。
   非有限值、缺失值和修复值应通过 mask 显式进入模型。

输出
----

基础版本输出 Student-t 或 Gaussian 分布参数：

- ``mu``：后验均值或位置参数。
- ``sigma``：尺度参数，表示 aleatoric uncertainty。
- ``nu``：Student-t 自由度，用于控制尾部厚度。

最终预测值可取后验均值：

.. math::

   \hat{\rho} = E[\rho \mid \tau, rewards] = \mu

当更关注稳健性时，也可以取后验中位数或预测区间。

设计原则
--------

- ``tau`` 与 ``rewards`` 是车辆-道路结构数据，不是时序数据。
- 车辆维度天然是集合，模型应尽量满足 permutation-invariant 或 permutation-equivariant。
- 训练目标应优化概率预测质量，首选 NLL，而不是只优化 MSE。
- 模型需要报告不确定性、校准表现和泛化性能。
